    // méthode

    Le carburant seul est ce que vous payez à la pompe. Le coût complet suit le barème kilométrique fiscal 2026 (revenus 2025) : amortissement, entretien, pneus et assurance compris, majoré de 20 % pour une voiture 100 % électrique. C'est une estimation, pas un conseil fiscal.

    // données

    Modèles : base Car Labelling de l'ADEME, valeurs d'homologation WLTP (sur la route, comptez souvent 15 à 20 % de plus ; sans hybrides rechargeables, GPL ni superéthanol). Prix du jour : data.economie.gouv.fr. Itinéraires : Géoplateforme de l'IGN. Lignes Aléop, aire de covoiturage et bornes : GéoBercé, territoire de Loir-Lucé-Bercé.

    // vie privée

    Rien n'est enregistré : les calculs se font sur votre appareil. Le prix du jour en Sarthe est demandé sans rien transmettre de vous. Seules les adresses tapées partent à l'IGN (data.geopf.fr) pour trouver les lieux et l'itinéraire.
