Boîte à vocaux

Simulateur du boîtier sans écran : un bouton pour parler, un bouton qui clignote quand papa ou maman répond.

Reste appuyé pour parler, relâche pour envoyer. Double appui : réécouter ton dernier message.
Clignote quand un message arrive. Appui : lire le suivant (ou passer). Appui long : tout lire.

Clavier : Espace = Parler · M = Messages

Mode

Comment configurer Telegram ?

1) Dans Telegram, parle à @BotFather, /newbot, copie le jeton.
2) Envoie un message à ton bot (ou ajoute-le au groupe famille ; dans un groupe, désactive « Group Privacy » dans BotFather > Bot Settings pour qu’il reçoive les vocaux).
3) Ouvre https://api.telegram.org/bot<jeton>/getUpdates et copie chat.id.
Le jeton reste dans le stockage local de ton navigateur ; seul le chat indiqué est écouté.
